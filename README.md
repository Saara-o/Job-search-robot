
# Job Listing Aggregator (RPA)

A software robot that collects job listings from multiple job portals into one file, saving job seekers from repetitive manual browsing.

Made for the Robotic Process and RPA course (TO00CD60-3003) at Laurea University of Applied Sciences.

## Authors

Atte Liikanen, Saara Orvas, Jiro Pärnänen

## What the robot does

1. Reads search criteria (keywords, location, job type) from user input
2. Searches selected job sites and extracts listings
3. Combines results and removes duplicates
4. Saves the unique listings to a CSV/Excel file
5. Notifies the user by email when finished
6. Logs errors and asks for human help if something fails
